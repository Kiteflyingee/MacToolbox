# MacToolbox 分发与公证说明

## 当前发行方式

0.2.18 官方通用 DMG 采用拖拽安装形式，包含 `MacToolbox.app`（`arm64` + `x86_64` 双架构）、指向系统 `/Applications` 的 `Applications` 快捷入口以及 `安装说明.txt`。GitHub Release 发布的官方通用 DMG 与应用均已使用 `Developer ID Application` 证书完成硬化运行时签名，并通过 **Apple Notary 公证与票据装订**（`Notarized Developer ID`），同时提供 `.sha256` 校验文件。

## 安装与首次打开

1. 打开 DMG，将 `MacToolbox.app` 拖到旁边的 `Applications`（更新时先退出旧版并选择替换）。
2. 推出 DMG，从“应用程序”打开 `MacToolbox.app`。
3. 官方 Release 安装包已完成 Apple 公证与 Gatekeeper 校验；首次从互联网下载打开时按系统常规确认提示点击“打开”即可（若自行使用 `MACTOOLBOX_ADHOC_SIGN=1` 从源码本地临时签名构建，才需要在右键菜单或“隐私与安全性”中手动允许打开）。
4. 首次触发相关功能时，按系统提示允许辅助功能和屏幕录制权限。

## 本地自建通用 DMG（可选 Ad-hoc 签名）

```sh
MACTOOLBOX_ADHOC_SIGN=1 MACTOOLBOX_ARCHITECTURES=universal MACTOOLBOX_BUILD_CONFIGURATION=release \
  MACTOOLBOX_APP_OUTPUT=/private/tmp/MacToolbox-release-$(id -u)/MacToolbox.app \
  sh tools/build_app.sh -Xswiftc -warnings-as-errors
MACTOOLBOX_ADHOC_SIGN=1 sh tools/package_dmg.sh /private/tmp/MacToolbox-release-$(id -u)/MacToolbox.app
```

生成的 `build/MacToolbox-0.2.18-universal.dmg` 及同名 `.sha256` 可通过以下命令校验完整性：

```sh
shasum -a 256 -c MacToolbox-0.2.18-universal.dmg.sha256
```

## 使用 Developer ID 签名与 Apple 公证（正式发布流程）

使用 Apple Developer ID 证书构建、打包与公证分发时，通过未纳入版本控制的本地 `tools/signing.local.env` 或环境变量传入签名身份（证书私钥与公证凭据仅保存在本机钥匙串）：

1. 在 [Apple 账户](https://account.apple.com/) 的“登录与安全 → App 专用密码”生成专用密码，运行 `tools/配置Apple公证.command` 将凭据存入本机钥匙串 profile（默认 `MacToolbox-notary`）。
2. 配置 `MACTOOLBOX_SIGNING_IDENTITY`（Developer ID Application 证书 SHA-1）与 `MACTOOLBOX_TEAM_ID`，然后按以下步骤完成签名、打包与公证：

```sh
MACTOOLBOX_REQUIRE_DEVELOPER_ID=1 MACTOOLBOX_ARCHITECTURES=universal MACTOOLBOX_BUILD_CONFIGURATION=release \
  MACTOOLBOX_APP_OUTPUT=/private/tmp/MacToolbox-release-$(id -u)/MacToolbox.app \
  sh tools/build_app.sh -Xswiftc -warnings-as-errors
MACTOOLBOX_REQUIRE_DEVELOPER_ID=1 sh tools/package_dmg.sh /private/tmp/MacToolbox-release-$(id -u)/MacToolbox.app
sh tools/notarize_dmg.sh "$PWD/build/MacToolbox-0.2.18-universal.dmg" MacToolbox-notary
```

脚本仅在 Apple 返回 `Accepted` 后装订票据（`stapler staple`），验证签名、Gatekeeper 与映像完整性，并重新生成 SHA-256。参考：[Apple 分发打包流程](https://developer.apple.com/documentation/xcode/packaging-mac-software-for-distribution)、[自定义公证流程](https://developer.apple.com/documentation/security/customizing-the-notarization-workflow)。
