# 开启屏幕录制权限

请先把 MacToolbox.app 拖到 Applications，再从“应用程序”打开。0.2.16 起，首次截图缺少权限时会显示分步引导；也可进入“偏好设置 → 权限”，点击“开启屏幕录制权限…”。

1. 点击引导中的“打开系统设置”。
2. 在“隐私与安全性 → 录屏与系统录音”页面找到 MacToolbox，开启开关。
3. **列表没有 MacToolbox 时，点屏幕录制应用列表下方的“＋”添加按钮**，选择 MacToolbox.app（通常位于“应用程序”），点“打开”，再开启开关。
4. 找不到 App 时，返回引导点“显示应用位置”；Finder 会选中当前运行的 App。
5. 如 macOS 提示“退出并重新打开”，按提示完成，再重试截图。

若从 DMG 或系统临时运行位置打开，应用会先提示安装到“应用程序”，并提供打开该文件夹的入口。

这些操作仍由你在系统中确认。新版补齐了列表缺少 App 时的指引与权限用途说明；macOS 27 上自动登记列表条目的原因尚未确认，仍需在该系统实机验证。引导界面已在 macOS 15.8 检查。

参考：[Apple 的 macOS 27 录屏与系统录音权限说明](https://support.apple.com/zh-cn/guide/mac-help/mchld6aa7d23/27/mac/27)。
